# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.1] - 2026-06-01

### Fixed

- Power pins of the TMS9928 symbol were not visible.

## [1.1.0] - 2026-06-01

### Added

- 3D models for DB25F, DB25M, DIN8, Joystick connector, angled push button, RCA (red, white, yellow), slot connector, and 5.5/2.1mm jack footprints.

## [1.0.0] - 2024-01-01

### Added

- Initial release of the Artemisa KiCad symbol and footprint libraries.
